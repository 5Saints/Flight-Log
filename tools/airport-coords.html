AIRPORT COORDINATE CALCULATOR

Computes the x/y SVG coordinates for a new Flight Log airport entry from its lat/lon, using the same Albers USA projection as the map. Reverse-engineered and calibrated against the 131 airports already in index.html (mean error 0.2px across 118 continental airports).

Scope: this projection is calibrated for the continental US (roughly lat 24–49.5, lon −125 to −66.5). Alaska, Hawaii, and international airports in the existing dataset are placed by hand near the map edges rather than true-projected — the same approach the app's own documentation describes. If your airport falls outside that range, use the computed point as a rough starting guess and nudge it visually against the rendered map instead of trusting it directly.

Note: the app's technical documentation describes a y-axis formula (based on published min/max bounds) that does not reproduce the actual stored coordinates — it's off by a constant offset. The constants below were instead fit directly against the real airport data and validated to sub-pixel accuracy, so trust this tool over that formula.
